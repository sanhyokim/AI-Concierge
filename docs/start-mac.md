# はじめての起動（Mac）

管理画面とブラウザー会話試験を、自分のMacで動かす手順です。**ターミナルにコマンドを入力する必要はありません。** 上から順に行ってください。

- 対象：macOS 12 以降。ブラウザーは Chrome・Edge・Safari のどれか。マイク付きのヘッドセット（推奨）。
- かかる時間：初回は約15分（Pythonを入れる時間を含む）。
- この手順で、会社の回線やLINEにつながることはありません。手順3までは、費用もかかりません。

---

## 手順1　Python を入れる（最初の1回だけ）

Mac に最初から入っている Python は古い（3.9）か、入っていないため、新しいものを入れます。

1. ブラウザーで https://www.python.org/downloads/ を開きます。
2. 黄色い「**Download Python 3.13**」（3.11 以上なら、ほかの番号でもかまいません）を押します。
3. ダウンロードした `python-3.13.x-macos11.pkg` を開き、「続ける」「同意する」「インストール」と進めます（Macのパスワードを聞かれたら入力します）。
4. **最後に開くフォルダー（Python 3.13）の「Install Certificates.command」をダブルクリックします。** ターミナルの画面に英語の文字が流れ、「[Process completed]」などと出たら、その画面は閉じてかまいません。
   - これは、OpenAI などとの通信（HTTPS）で相手を確かめるための証明書を、Python に入れる作業です。行わないと、試験の開始で「URLError」「CERTIFICATE_VERIFY_FAILED」と出て、AIにつながりません。
   - フォルダーを閉じてしまったときは、Finder →「アプリケーション」→「Python 3.13」の中にあります。
   - 忘れても、`start_mac.command` が起動のたびに確かめ、Mac 本体の証明書で代わりに動かします。それでもだめなときは、このファイルを案内します。

## 手順2　プログラムをダウンロードして、展開する

1. ブラウザーで GitHub に**ログインした状態で**、次のアドレスを開きます。ZIPファイルのダウンロードが始まります。

   https://github.com/sanhyokim/AI-Concierge/archive/refs/heads/claude/new-session-w4sjel.zip

   - 「404」と出たときは、GitHub にログインしていません。ログインしてから、もう一度開きます。
2. 「ダウンロード」フォルダーの `AI-Concierge-claude-new-session-w4sjel.zip` を**ダブルクリック**します。同じ名前のフォルダーができます（Safari では自動で展開されることもあります）。
3. そのフォルダーの中に `start_mac.command` があることを確かめます。
   - 同じフォルダーにある `start_windows.bat` は Windows 用です。Mac で開いても、`@echo off` などの文字が表示されるだけです。

## 手順3　起動して、オフラインの模擬で動作を確かめる（APIキー不要・費用0円）

1. `start_mac.command` を開きます。**初回だけ、次のようにします。**
   - `start_mac.command` を **右クリック（または control キーを押しながらクリック）→「開く」** を選びます。
   - 「開発元を確認できないため開けません」「開いてもよろしいですか？」と出たら、**「開く」** を押します。
   - 「開く」が出ない場合：アップルメニュー →「システム設定」→「プライバシーとセキュリティ」の下の方にある「このまま開く」を押し、もう一度開きます。
   - 2回目からは、ダブルクリックで開けます。
2. 「ターミナル」の画面が開きます。**最初の1回だけ**、管理画面のパスワードを決めます。
   - 「管理画面のパスワードを決めて入力し、Enter」と出たら、8文字以上のパスワードを入力して return キーを押します。**入力しても画面には何も表示されませんが、入っています。**
   - 「同じパスワードをもう一度」と出たら、同じものを入力して return キーを押します。
   - このパスワードは控えておいてください（ユーザー名は `admin` です）。
3. APIキーを聞かれます。**今回は何も入力せずに return キーを2回**押します。
4. 「準備ができました」と出て、ブラウザーが開きます。
   - 「"Python" に受信接続を許可しますか？」と出たら、「拒否」でかまいません（このMacの中だけで使うため）。
   - ブラウザーが開かないときは、ブラウザーの住所の欄に `http://127.0.0.1:8780/lab/` と入力します。
5. ユーザー名 `admin` と、決めたパスワードでログインします。
6. 「ブラウザー会話試験」の画面が開きます。
   - マイクの使用を聞かれたら、**「許可」**を押します。
   - 候補で **「オフラインの模擬」** を選び、「会話を始める」を押します。ヘッドセットに向かって話すと「マイク」のメーターが動き、電子音が鳴ります。「終える」で終了します。
7. ここまでできれば、Macでの準備は完了です。**ターミナルの画面は、試験が終わるまで閉じないでください。** 閉じるとサーバーが止まります。

## 手順4以降

APIキーの用意、最初の会話、会話試験の段取り（C1〜C7）は、[はじめての起動（Windows）](./start-windows.md) の手順4・手順5と「会話試験の段取り」と同じです。次のところだけ、読み替えてください。

| Windows | Mac |
| --- | --- |
| `start_windows` をダブルクリック | `start_mac.command` をダブルクリック |
| 黒い画面 | ターミナルの画面 |
| 貼り付けは Ctrl+V | 貼り付けは ⌘+V |
| Enter キー | return キー |
| `reset_password_windows`（パスワードを忘れたとき） | `reset_password_mac.command`（初回は右クリック →「開く」） |
| 結果のファイル `prototype\results\browser-lab` | `prototype/results/browser-lab` |
| 毎回の貼り付けを省く（環境変数） | 行わず、毎回貼り付けます（パスワード管理ソフトに保管） |

## うまくいかないとき

| 画面に出たこと・起きたこと | 原因と対処 |
| --- | --- |
| 開いたら `@echo off` `chcp 65001` などの文字が表示された | Windows 用の `start_windows.bat` を開いています。閉じて、`start_mac.command` を開きます（初回は右クリック →「開く」）。`start_mac.command` が見当たらないときは古いZIPなので、手順2のとおりダウンロードし直します |
| 「開始できませんでした：…: URLError」、または「CERTIFICATE_VERIFY_FAILED」「証明書を確かめられません」 | Python に HTTPS の証明書が入っていません。手順1の4（Install Certificates.command をダブルクリック）を行い、ターミナルの画面を閉じてから `start_mac.command` を開き直します。この失敗は OpenAI に届いていないため、回数にも費用にも数えません |
| ターミナルに「インターネットにつながっていないようです」 | Wi-Fi などを確かめて、開き直します。つながらないままでも、オフラインの模擬は使えます |
| 「開発元を確認できないため開けません」 | 手順3の1のとおり、右クリック →「開く」で開きます |
| 「Python 3.11 以上が見つかりません」 | 手順1を行います。入れた後も同じなら、ターミナルの画面を閉じてから、もう一度開きます |
| 「このファイルは、ZIP を展開したフォルダーの中から開いてください」 | 展開したフォルダーの中の `start_mac.command` を開きます |
| 「アクセス権がありません」「実行できません」 | ファイルの実行の許可が失われています。ZIPをダウンロードし直して、Macの標準の方法（ダブルクリック）で展開します |
| 「ポート 8780 が使われています」 | 前に開いたターミナルの画面が残っています。閉じてから、もう一度開きます |
| マイクのメーターが動かない | ① ブラウザーの住所の欄の左のアイコンで、マイクを「許可」。② アップルメニュー →「システム設定」→「プライバシーとセキュリティ」→「マイク」で、使っているブラウザーをオンにする。③ ヘッドセットを、Macの入力の機器にする（「システム設定」→「サウンド」→「入力」） |
| 会話を始めても電子音しか聞こえない | 候補が「オフラインの模擬」になっています。「1. 候補と条件」の **候補** で「OpenAI GPT-Live 1」などを選びます |
| ターミナルに英語のエラー（Traceback …）が出て止まった | `Traceback` から最後の行までをマウスでなぞって選び、⌘+C でコピーして、開発の担当（Claude）に送ってください。キーやパスワードは画面に表示されないので、そのまま送ってかまいません |

## 確認できていること・できていないこと

- 開発のサーバーで、起動のファイルの分かれ道（Pythonがない・古い・展開したフォルダーの外、証明書がない・Mac 本体の証明書で代わりに動かす・インターネットにつながらない）と、起動（パスワードとキーの入力からログインまで）を確かめています。
- 実際のMacでのダブルクリックからの起動は、開発のサーバーでは試せません。最初にお使いの画面で確かめていただく必要があります。
