# はじめての起動（Windows）

管理画面とブラウザー会話試験を、自分のWindowsのPCで動かす手順です。**コマンドを入力する必要はありません。** 上から順に行ってください。

- 対象：Windows 10・11。ブラウザーは Chrome か Edge。マイク付きのヘッドセット（推奨）。
- かかる時間：初回は約15分（Pythonを入れる時間を含む）。
- この手順で、会社の回線やLINEにつながることはありません。手順3までは、費用もかかりません。

> **PowerShell やコマンドプロンプトに、コマンドを入力しないでください。** mac・Linux用の書き方（`read -rs ...` や `python3 ...`）は、Windowsでは動きません。この手順では、ファイルをダブルクリックするだけで起動します。

---

## 手順1　Python を入れる（最初の1回だけ）

1. スタートメニューから **Microsoft Store** を開きます。
2. 上の検索欄に `Python 3.13` と入力し、検索します。
3. 発行元が **Python Software Foundation** の「Python 3.13」を選び、**入手**（または「インストール」）を押します。
   - 3.11 以上なら、3.12 や 3.14 でもかまいません。
4. インストールが終わったら、Microsoft Store を閉じます。

> Microsoft Store が使えない場合は、https://www.python.org/downloads/ からインストーラーを入れます。古い形式のインストーラーの場合は、最初の画面の下の **「Add python.exe to PATH」にチェック**を入れてから「Install Now」を押します。

## 手順2　プログラムをダウンロードして、展開する

1. ブラウザーで GitHub に**ログインした状態で**、次のアドレスを開きます。ZIPファイルのダウンロードが始まります。

   https://github.com/sanhyokim/AI-Concierge/archive/refs/heads/claude/new-session-w4sjel.zip

   - 「404」と出たときは、GitHub にログインしていません。ログインしてから、もう一度開きます。
   - 画面から行う場合：リポジトリの画面で、左上のブランチの切り替えを `claude/new-session-w4sjel` にし、緑の「Code」→「Download ZIP」を押します。
2. エクスプローラーで「ダウンロード」フォルダーを開き、`AI-Concierge-claude-new-session-w4sjel.zip` を**右クリック →「プロパティ」**を開きます。
   - 下の方に「セキュリティ：このファイルは他のコンピューターから取得したものです」があれば、**「許可する」にチェック**を入れて「OK」を押します（後の警告が出にくくなります）。なければ、そのまま「OK」。
3. 同じZIPを**右クリック →「すべて展開」→「展開」**を押します。
4. 開いたフォルダーの中に `AI受付を起動_windows`（種類：Windows バッチ ファイル）があることを確かめます。
   - 同じ名前のフォルダーが2重になっていることがあります。`AI受付を起動_windows` が見えるところまで開いてください。
   - ZIPを使うのは、この最初の1回だけです（2026-10-20〜）。次からは、デスクトップの「AI受付を起動」が最新版を自分で入れます。

## 手順3　起動して、オフラインの模擬で動作を確かめる（APIキー不要・費用0円）

1. `AI受付を起動_windows` を**ダブルクリック**します（最初の1回だけ）。
   - 青い画面「Windows によって PC が保護されました」が出たら、**「詳細情報」→「実行」**を押します。
   - 「発行元を確認できませんでした」と出たら、**「実行」**を押します。
   - 黒い画面に「最新版を入れました」「デスクトップに「AI受付を起動.bat」を作りました」と出ます。プログラムは `C:\Users\（あなたの名前）\AI-Concierge` に入ります。前に使っていたフォルダーがあれば、そこから開くと、記録・パスワード・試験の結果を引き継ぎます。
2. 黒い画面が開きます。**最初の1回だけ**、管理画面のパスワードを決めます。
   - 「管理画面のパスワードを決めて入力し、Enter」と出たら、8文字以上のパスワードを入力して Enter を押します。**入力しても画面には何も表示されませんが、入っています。**
   - 「同じパスワードをもう一度」と出たら、同じものを入力して Enter を押します。
   - このパスワードは控えておいてください（ユーザー名は `admin` です）。
3. APIキーを聞かれます。**今回は何も入力せずに Enter を5回**押します（OpenAI・Google・ElevenLabs・xAI・Phonic の5つ）。
4. 「準備ができました」と出て、ブラウザーが開きます。
   - 「Windows セキュリティの重要な警告」（ファイアウォール）が出たら、「キャンセル」でかまいません（このPCの中だけで使うため）。
   - ブラウザーが開かないときは、ブラウザーの上の住所の欄に `http://127.0.0.1:8780/test` と入力します。
5. ログインの画面で、ユーザー名 `admin` と、決めたパスワードを入力します。
6. 「試験」の画面が開きます（左のメニューの「試験」。上の「声で話す」が選ばれています。2026-10-26〜）。
   - 画面は上から順に「1 AIを選ぶ」「2 声を選ぶ」「3 台本を選ぶ」「4 電話をかける」「5 終わったら、判定して保存」です。
   - 「1 AIを選ぶ」で **「オフラインの模擬」** の札を押し、「4 電話をかける」の大きなボタン **「電話をかける」** を押します。
   - マイクの使用を聞かれたら、**「許可する」**を押します。
   - ヘッドセットに向かって話すと、「マイク」のメーターが動き、ピーという模擬の音が鳴ります。
   - 赤い **「電話を切る」** を押して終了します。
7. ここまでできれば、PCでの準備は完了です。**黒い画面は、試験が終わるまで閉じないでください。** 閉じるとサーバーが止まります。

## 手順4　APIキーを用意する（利用者が判断した後）

アカウントの作成と前払いは、新しい契約と支払いにあたります。行うと決めた後に進めてください。画面の名前は、各社の変更で変わることがあります。

**OpenAI（GPT-Live 1）**

1. https://platform.openai.com/ にログインします（アカウントがなければ作ります）。
2. 支払い（Billing）で、前払いのクレジットを購入します（最低 $5）。**自動の追加購入（Auto recharge）はオフ**にします。
3. 使用額の上限と通知を設定します。前払いの残高も、この上限も、確実に止まる上限ではありません（集計の遅れで超えることがあります）。
4. 「API keys」で「Create new secret key」を押し、名前（例：`ai-concierge-test`）を付けて作ります。
5. 表示されたキー（`sk-` で始まる長い文字列）をコピーします。**キーはこの1回しか表示されません。**

**Google AI Studio（Gemini 3.8 Live）**

1. https://aistudio.google.com/ に Google アカウントでログインします。初めてのときは、利用規約に同意します。
2. 左の「**Get API key**」を開き、「**Create API key**」を押します。初めて使うアカウントでは、プロジェクトとキーが自動で1つ作られていることがあります。そのときは、そのキーを使ってかまいません。
3. キーの欄をコピーします。今作るキーは `AQ.` で始まります（2026年5月28日より前に作ったキーは `AIza` で始まります）。どちらでも使えます。
4. 支払いの設定（Billing）をしなければ、無料枠のままです。Gemini 3.8 Live は無料枠で使えますが、話した内容はGoogleの製品の改善に使われ、人が読むことがあります。**架空の情報だけ**で話してください。

**ElevenLabs（Eleven Realtime）**（利用者の決定、2026-10-21）

1. https://elevenlabs.io/ を開き、右上の「**Sign up**」でアカウントを作ります（Google アカウントでも作れます）。
   - 最初に「**プラットフォームを選択してください**」と出たら、右の「**ElevenAgents**」（会話型エージェント）を選んで「**続行**」を押します（2026-10-21、利用者のPCで確認。後から切り替えられます）。
   - 画面が日本語のときは、下の英語の名前が日本語で出ます（Developers＝デベロッパー、API Keys＝APIキー など。2026-10-21 の画面では、左のメニューのいちばん下、「アップグレード」の上に「デベロッパー」がある）。
   - 次に「**ElevenAgentsへようこそ**」（どのようなタイプのエージェントを作成したいですか？）と出ます。**エージェントは作らなくてかまいません**（会話試験は、指示と声をこのプログラムから渡すので、ElevenLabs の画面のエージェントは使いません）。先に進む必要があれば、いちばん下の「**空のエージェント**」を選び、名前は「テスト」などにして、中身は設定しません。
2. 最初は無料のプランのままでかまいません。料金表では、いちばん下のプランにも v1 Max の会話が約12分含まれるように書かれています（どのプランの分かは料金表に書かれていないため、未確認です）。足りなくなったら、Starter（$6/月）などのプランを選びます。**プランを選ぶのは、新しい支払いになります。**
3. 左のメニューの下のほうの「**Developers**」（デベロッパー。左のメニューのいちばん下）から「**API Keys**」（APIキー）を開き、「**Create API Key**」（APIキーを作成）を押します。
   - 名前は `ai-concierge-test` などにします。
   - 権限（Permissions）を選ぶ画面が出たら、「**ElevenAgents**」（Conversational AI）を「Write」（書き込み）にします。分からなければ、制限なしのままでもかまいません。
4. 表示されたキー（`sk_` で始まる長い文字列）をコピーします。**キーはこの1回しか表示されません。**
5. Eleven Realtime は、ElevenLabs が順に使えるようにしている途中です（2026-10-21 の公式資料）。アカウントによっては、まだ使えないことがあります（下の「うまくいかないとき」）。
6. 話した内容の扱いは、ElevenLabs の規約によります。**架空の情報だけ**で話してください。

**xAI（Grok Voice 3.0）**（利用者の決定、2026-10-23）

1. https://console.x.ai/ を開き、アカウントを作ります（メールアドレス、Google アカウント、X のアカウントのどれでも作れます）。
   - 名前や使い道（例「電話受付AIの試験」）を聞かれたら入力し、API の規約に同意します。
   - **「データ共有の制度」（話した内容を xAI に渡す代わりに、毎月クレジットがもらえる、という案内）は選ばないでください。** 試験でも、お客様の会話を渡す設定にしないためです。
2. 左の「**Billing**」（支払い）を開きます。
   - 新しいアカウントには、$25 のクレジット（30日の期限）が付くと、解説の記事に書かれています（xAI の料金表には書かれていないので、画面の残高で確かめます）。残高があれば、支払いの設定はまだしなくてかまいません。
   - 残高がない、または足りなくなったら、クレジットを購入します。**これは新しい支払いになります。** 自動の補充（auto-recharge）は**オフ**にし、月の上限（monthly limit）と通知を設定します。
3. 左の「**API Keys**」を開き、「**Create API Key**」を押します。「**New API key**」の画面が出ます（2026-10-23、利用者の画面で確認）。
   - 上の切り替えで、「Cursor」ではなく「**Grok API**」を選びます（「Cursor」は、プログラムを書くアプリ向けのキーです）。
   - **Name**（名前）は `ai-concierge-test` などにします。
   - **Expires**（期限）は「180 days (recommended)」のままでかまいません。期限が来たらキーを作り直し、デスクトップの「APIキーを入れ直す」から入れ直します。
   - **Permissions**（権限）は、音声（Voice / Realtime）が入っていれば、そのままでかまいません。分からなければ、すべて許可します。
   - 「**Create key**」を押します。
4. 表示されたキー（`xai-` で始まる長い文字列）をコピーします。**キーはこの1回しか表示されません。**
5. 料金は、つながっている時間1分あたり $0.08 です（黙っている間もかかります。3分で約36円）。
6. 話した内容の扱いは、xAI の規約によります。**架空の情報だけ**で話してください。

**Phonic（Phonic-1）**（利用者の依頼、2026-10-29「すぐにテストしたい」）

Phonic-1 は、2026-10-29 に出たばかりです。下の画面の名前は Phonic の資料から書いたもので、まだ実際の画面で確かめていません。違う名前が出たら、そのまま教えてください。

1. https://phonic.ai/ を開き、右上の「**Start building**」でサインインの画面に進み、アカウントを作ります（メールアドレスか Google アカウント）。

   - **プランを選ぶ画面や、$250 のクレジットの案内は出ません**（2026-10-30、利用者の画面で確認）。料金のページには「11月30日までの登録で $250」とありますが、どうやって付くのかは書かれていません。管理画面の支払い（Billing）や使用量（Usage）の画面に残高が出ていれば、それが無料の分です。
   - 料金のページのよくある質問には「Starter は月 $0 で、毎月 $30 のクレジット付き」ともあります。最初はそれで試せる見込みです（未確認）。

2. 左のメニューか右上の自分の名前のメニューから「**API Keys**」（または「Settings」→「API Keys」）を開き、「**Create API Key**」（または「New key」）を押します。
   - 名前は `ai-concierge-test` などにします。
3. 表示されたキー（長い文字列）をコピーします。**キーは一度しか表示されないことがあります。** Phonic のキーが何という文字で始まるかは、資料に書かれていません。
4. エージェント（Agent）を作る画面が出ても、**作らなくてかまいません**。会話試験は、指示・声・業務処理をこのプログラムから渡します。
5. 料金は、話している時間1分あたり $0.07 です（3分で約35円。AIの文字の量による追加の料金はありません）。
6. 話した内容の扱いは、Phonic の規約によります。**架空の情報だけ**で話してください。

**キーの扱い**

- キーは、チャット・メール・LINE・Word などに貼らないでください。
- キーは毎回の起動で貼り付けます（このプログラムは、キーをファイルに保存しません）。保管にはパスワード管理ソフトを使ってください。
- 毎回の貼り付けを省きたい場合（任意）：スタートメニューで「環境変数」と検索 →「**環境変数を編集**」（自分のアカウント用）→ 上の欄の「新規」→ 変数名 `OPENAI_API_KEY`（Geminiは `GEMINI_API_KEY`、ElevenLabsは `ELEVENLABS_API_KEY`、xAIは `XAI_API_KEY`、Phonicは `PHONIC_API_KEY`）、値にキーを貼り付け →「OK」。次の起動から「設定済み」と表示され、聞かれなくなります。このPCの中に、キーが保存されることになります。

## 手順5　GPT-Live・Gemini で最初の会話をする

1. 黒い画面が開いたままなら、閉じます（前のサーバーを止めます）。
2. デスクトップの「AI受付を起動」をダブルクリックします。
3. 「OpenAI（GPT-Live 1）のAPIキー」と出たら、コピーしたキーを**貼り付けて（Ctrl+V、または右クリック）Enter** を押します。
   - 画面には何も表示されませんが、入っています。
   - 「受け付けました（sk- で始まる ○○ 文字）」と出れば成功です。
   - 「形が違うようです」と出たら、キーの一部しかコピーできていません。コピーし直して貼り付けます。
4. Gemini・ElevenLabs・xAI・Phonic のキーも同じように貼り付けます（使わないときは、何も入力せずに Enter）。
   - 前にキーを保存したPCでは、次の起動で、まだ保存していないキー（2026-10-29〜は Phonic のキー）だけを1回聞かれます。貼り付けると、全部まとめて保存します。何も入力せずに Enter を押すと、起動のたびに聞かれます。
   - Phonic のキーは、何の文字で始まるかが決まっていないので、「受け付けました（○○ 文字）」と文字数だけが出ます。
   - キーを後から入れるときは、デスクトップの「APIキーを入れ直す」から起動しても入れられます（そのときは、5つのキーをすべて貼り付け直します）。
   - 「このPCに暗号化して保存しました」と出ます。次からは、キーは聞かれません（2026-10-20〜）。キーを変えるときは、デスクトップの「APIキーを入れ直す」から起動します。
5. ブラウザーでログインし、「試験」の画面の「1 AIを選ぶ」で「OpenAI GPT-Live 1」（または「Google Gemini 3.8 Live」「ElevenLabs Eleven Realtime v1 Max」「xAI Grok Voice 3.0」「Phonic Phonic-1」）の札を押します。札には、3分の電話1回の費用の目安と、使えるかどうか（キーが未設定なら押せません）が出ています。受付の試験には、Eleven Realtime は v1 Max を使います（v1 Mini は会話の自然さを比べる用です）。「オフラインの模擬」のままだと、電子音しか鳴りません。
   - 開始の回数の上限はありません。1回の会話は5分で自動的に止まります。
   - 「電話をかける」を押すと、AIが自分の声で冒頭の案内（「お電話ありがとうございます。株式会社野田、AIオペレーターでございます。…お気軽にお話しください。」）を話します。聞き終えてから話し始めます。
   - 話している間、AIとお客様（あなた）のセリフが、ボタンの下にチャットのように並びます。
6. 「3 台本を選ぶ」の C1〜C7 のボタンから1つ選びます。選んだ台本だけが下に出て、話すセリフが番号の順に書いてあるので、「電話をかける」を押した後、そのとおりに読み上げます。最初はC2がおすすめです。
   - AIが別の順番で聞いてきたら、聞かれたことに合わせて、カードのセリフで答えます。
   - 話し終えたら「以上です」と言います。AIが最後のあいさつ（「お電話ありがとうございました。…失礼いたします。」）をして、3秒ほど後に「ツー・ツー・ツー」と電話を切ります。切れないときは「電話を切る」を押します（押し忘れても5分で止まります）。
7. 会話を終えると、結果は自動で保存されます。判定とメモを記入して「結果を保存」を押すと、同じファイルに書き足します。
8. 「試験」の画面の上の「費用」で、その会話の留保が「照合待ち」になっていることを確かめます。後日、業者の利用画面で見た実際の額を入力して照合します。

## 会話試験の段取り（C1〜C7）

1. デスクトップの「AI受付を起動」で起動して（最新版に自動で入れ替わります）、キーを貼り付けます。
2. 「試験」の画面の「1 AIを選ぶ」で、試すAIの札が選ばれている（青い枠）ことを確かめます。
3. 台本のカードを **C1 から順に、1枚につき1回の会話** で行います。
   1. 台本を選び、「電話をかける」を押します。
   2. カードのセリフを、番号の順に読み上げます。AIが別の順番で聞いてきたら、聞かれたことに合わせて答えます。
   3. 話し終えたら「以上です」と言います。AIが最後のあいさつの後に電話を切ります（ツー・ツー・ツー）。切れないときは「電話を切る」を押します（押し忘れても5分で止まります）。
   4. 「判定」の欄（選んでいる台本の分だけが出ます）を「はい・いいえ」で記入し、気づいたことをメモに書いて「結果を保存」を押します（会話の終わりに自動で保存されたファイルに書き足します）。
4. C1〜C7 が終わったら、開発の担当（Claude）に次を送ってください。
   - カードごとの一言の感想（よかった点・おかしかった点）
   - 「試験」の画面の「費用」の「試験の会話」の表の写真
   - 保存した結果のファイル（フォルダーの中の `prototype\results\browser-lab` にある `.json`）。チャットに添付します。架空の情報だけなので、添付してかまいません
   - 会話の記録：管理画面の受付記録（「声で話す」の画面の「受付記録を開く」）の上にある「記録をテキストで保存」を押すと、`call-（受付の番号）.txt` がダウンロードのフォルダーに入ります。そのファイルをチャットに添付します（出来事の記録を手で写す必要はありません。2026-10-20〜）
5. Gemini は、Google AI Studio のキーを用意した後に、同じ段取りで行います。

- 費用の目安：GPT-Live は1回あたり約$0.16（約25円）。C1〜C7で約$1.1です。OpenAIの月の予算（$10）の範囲です。
- C1 では、日付の確認も行います（「明後日でお願いします」→「明後日って何日でしたっけ？」）。AIには通話の開始時の日付と曜日、向こう14日の早見表を渡しています。答えが2日後の日付・曜日と違えば、メモに書いてください。
- C7（ふだんの話し方）は、名乗らずに質問から入るなど、実際のお客様に近い話し方です。採用を決めるうえで、いちばん大事な試験です。

## 終えるとき・次に使うとき

- **終えるとき**：ブラウザーで「電話を切る」→ 判定を記入して「結果を保存」→ 黒い画面を閉じます。
- **次に使うとき**：デスクトップの **「AI受付を起動」** をダブルクリックします（2026-10-20〜）。
  - 新しい版があれば、自動でダウンロードして入れ替えてから起動します。「最新版を入れました」または「最新版です」と出ます。ZIPのダウンロードや展開、記録の移しかえは要りません。
  - パスワードは聞かれません。キーも、最初に入れた後は聞かれません（このPCに暗号化して保存します。このWindowsのユーザーだけが読めます）。
  - **キーを変えるとき**（新しいキーを作った、別のAPIにする、など）：デスクトップの **「APIキーを入れ直す」** をダブルクリックします。保存していたキーを消して、新しいキーを聞いてから起動します。
  - インターネットにつながらないときは、いまの版で起動します。
- **パスワードを忘れたとき**：黒い画面を閉じてから、`reset_password_windows` をダブルクリックし、新しいパスワードを2回入力します。
- **記録の場所**：`C:\Users\（あなたの名前）\AI-Concierge` の中です。受付の記録とパスワードは `prototype\data`、会話試験の結果は `prototype\results\browser-lab`、費用の台帳は `prototype\results\usage-ledger.jsonl` です。自動の入れ替えでも、これらは引き継がれます。
- **前に展開したフォルダー**（「ダウンロード」の中の `AI-Concierge-claude-new-session-w4sjel` など）：「AI受付を起動」ができた後は使いません。消してかまいません。

## Eleven Realtime の声を日本語の声にする

Eleven Realtime は、何も設定しないと ElevenLabs の標準の声（英語の声）で話します。日本語の声に変えるには、次のようにします（2026-10-21〜）。

1. ElevenLabs の画面で、左の「**Voices**」（声）を開き、「**Explore**」（声の一覧）で言語を「**Japanese**」にしぼります。
2. 声を試聴して、受付に合う声を選びます。声の「…」のメニューから「**Copy voice ID**」（声のIDをコピー）を押します。英数字20文字ほどの文字列です。必要なら「Add to my voices」も押します。
3. 管理画面の左の「**音声**」を開き、「**＋ 声を追加**」を押します。
   - 表示名：例「ElevenLabsの日本語の声（女性）」
   - 接続候補：「ElevenLabs Eleven Realtime v1 Max」（Mini でも試すなら、同じ声をもう1行、Mini で追加します）
   - 声（名前・ID）：コピーした声のIDを貼り付けます。
4. 「**保存**」を押します。「使う」の丸は変えなくてかまいません（Eleven Realtime の会話では、Eleven Realtime の行の声を使います）。
5. 声のIDで受け付けられるかは、まだ確かめていません。断られたときは、記録に「最小の設定でつないでいます」と出て、標準の声で話します。

## 声を選ぶ（2026-10-21〜。2026-10-26 から札で選ぶ）

「試験」の「声で話す」の **「2 声を選ぶ」** に、選んだAIの声が札で並びます。札には「女性」「男性」の印と、声の特徴（「しっかり」「明るい」など）が出ます。「非公式」と書いてあるものは、AIの会社の資料に性別の記載がなく、ほかの資料や一般的な評価によるものです。「資料なし」は、見つからなかったものです。

- 一覧に出るのは、管理画面の「音声」で、そのAIに登録した声です（表示名で出ます。例「女性」「男性」）。
- そのAIで使えるのに、まだ登録していない声は、声の名前（例「Charon」）で出ます。試しに聞いてみて、気に入ったら「音声」で表示名を付けて登録します。
- 「AIの会社の標準の声」は、声を指定せずにつなぎます。
- 何も選ばなければ、「音声」で「使う」にした声（そのAIの声なら）か、そのAIの最初の声になります。
- 声ごとの違い（2026-10-21 時点）：
  - GPT-Live 1：日本語の声は harema（女性）と shida（男性）の2つです。どちらも登録済みです。marin は標準の声（日本語専用ではない）です。
  - Gemini 3.8 Live：Kore（登録済み）のほかに、Aoede・Leda・Puck・Charon・Orus を選べます。Google の資料にあるのは声の特徴だけ（Kore「しっかり」、Aoede「さわやか」、Leda「若々しい」、Puck「明るい」、Charon「説明向き」、Orus「しっかり」）で、性別の記載はありません。女性（Kore・Aoede・Leda）・男性（Puck・Charon・Orus）は一般的な評価です。
  - Eleven Realtime：上の手順で登録した声だけが出ます。声を何本も登録して、表示名で選び分けられます。
  - Grok Voice 3.0（2026-10-23〜）：ara・eve（女性）、leo・rex・sal（男性）を選べます（xAI の声の表が読めなかったため、ほかの資料によるもの）。どの声も日本語を話します（日本語専用の声はありません）。最初は ara です。
  - Phonic-1（2026-10-29〜）：hikari（女性。Phonic の説明に「日本語のなまり」とある声）・tomoya（男性）・sabrina（Phonic の標準の声）を選べます。日本語のために作った声とは書かれていないので、聞いて確かめます。最初は hikari です。

## エラーの文字のコピーの仕方

1. 黒い画面で、`Traceback` から最後の行までを、マウスでなぞって選びます（文字が白く反転します）。
2. **Enter キー**を押します（または右クリック）。これでコピーされます。
   - Windows ターミナルの画面の場合は、選んだ後に Ctrl+C でもコピーできます。
3. チャットに貼り付けて（Ctrl+V）送ります。
4. 黒い画面は、何かキーを押すと閉じます。**閉じる前にコピー**してください。

## 確認できていること・できていないこと

- 開発のサーバーで、日本語のWindowsと同じ条件（ファイルの既定の文字コードが Shift_JIS、時刻帯のデータがない）を作り、起動（パスワードとキーの入力からログインまで）と、すべての自動試験が通ることを確かめています。
- Windowsそのものでのダブルクリックからの起動は、開発のサーバーでは試せません。最初にお使いの画面で確かめていただく必要があります。
