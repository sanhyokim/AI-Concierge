# はじめての起動（Windows）

管理画面とブラウザー会話試験を、自分のWindowsのPCで動かす手順です。**コマンドを入力する必要はありません。** 上から順に行ってください。

- 対象：Windows 10・11。ブラウザーは Chrome か Edge。マイク付きのヘッドセット（推奨）。
- かかる時間：初回は約15分（Pythonを入れる時間を含む）。
- この手順で、会社の回線やLINEにつながることはありません。手順3までは、費用もかかりません。

> **PowerShell やコマンドプロンプトに、コマンドを入力しないでください。** mac・Linux用の書き方（`read -rs ...` や `python3 ...`）は、Windowsでは動きません。この手順では、ファイルをダブルクリックするだけで起動します。

---

## 手順1　Python を入れる（最初の1回だけ）

1. スタートメニューから **Microsoft Store** を開きます。
2. 上の検索欄に `Python 3.13` と入力し、検索します。
3. 発行元が **Python Software Foundation** の「Python 3.13」を選び、**入手**（または「インストール」）を押します。
   - 3.11 以上なら、3.12 や 3.14 でもかまいません。
4. インストールが終わったら、Microsoft Store を閉じます。

> Microsoft Store が使えない場合は、https://www.python.org/downloads/ からインストーラーを入れます。古い形式のインストーラーの場合は、最初の画面の下の **「Add python.exe to PATH」にチェック**を入れてから「Install Now」を押します。

## 手順2　プログラムをダウンロードして、展開する

1. ブラウザーで GitHub に**ログインした状態で**、次のアドレスを開きます。ZIPファイルのダウンロードが始まります。

   https://github.com/sanhyokim/AI-Concierge/archive/refs/heads/claude/new-session-w4sjel.zip

   - 「404」と出たときは、GitHub にログインしていません。ログインしてから、もう一度開きます。
   - 画面から行う場合：リポジトリの画面で、左上のブランチの切り替えを `claude/new-session-w4sjel` にし、緑の「Code」→「Download ZIP」を押します。
2. エクスプローラーで「ダウンロード」フォルダーを開き、`AI-Concierge-claude-new-session-w4sjel.zip` を**右クリック →「プロパティ」**を開きます。
   - 下の方に「セキュリティ：このファイルは他のコンピューターから取得したものです」があれば、**「許可する」にチェック**を入れて「OK」を押します（後の警告が出にくくなります）。なければ、そのまま「OK」。
3. 同じZIPを**右クリック →「すべて展開」→「展開」**を押します。
4. 開いたフォルダーの中に `start_windows`（種類：Windows バッチ ファイル）があることを確かめます。
   - 同じ名前のフォルダーが2重になっていることがあります。`start_windows` が見えるところまで開いてください。
   - このフォルダーは、後でも使います。分かりやすい場所（デスクトップなど）に移してもかまいません。

## 手順3　起動して、オフラインの模擬で動作を確かめる（APIキー不要・費用0円）

1. `start_windows` を**ダブルクリック**します。
   - 青い画面「Windows によって PC が保護されました」が出たら、**「詳細情報」→「実行」**を押します。
   - 「発行元を確認できませんでした」と出たら、**「実行」**を押します。
2. 黒い画面が開きます。**最初の1回だけ**、管理画面のパスワードを決めます。
   - 「管理画面のパスワードを決めて入力し、Enter」と出たら、8文字以上のパスワードを入力して Enter を押します。**入力しても画面には何も表示されませんが、入っています。**
   - 「同じパスワードをもう一度」と出たら、同じものを入力して Enter を押します。
   - このパスワードは控えておいてください（ユーザー名は `admin` です）。
3. APIキーを聞かれます。**今回は何も入力せずに Enter を2回**押します。
4. 「準備ができました」と出て、ブラウザーが開きます。
   - 「Windows セキュリティの重要な警告」（ファイアウォール）が出たら、「キャンセル」でかまいません（このPCの中だけで使うため）。
   - ブラウザーが開かないときは、ブラウザーの上の住所の欄に `http://127.0.0.1:8780/lab/` と入力します。
5. ログインの画面で、ユーザー名 `admin` と、決めたパスワードを入力します。
6. 「ブラウザー会話試験」の画面が開きます。
   - マイクの使用を聞かれたら、**「許可する」**を押します。
   - 候補で **「オフラインの模擬」** を選び、「会話を始める」を押します。
   - ヘッドセットに向かって話すと、「マイク」のメーターが動きます。「AIの音」（ピーという模擬の音）が鳴り、下の記録に行が増えます。
   - 「終える」を押して終了します。
7. ここまでできれば、PCでの準備は完了です。**黒い画面は、試験が終わるまで閉じないでください。** 閉じるとサーバーが止まります。

## 手順4　APIキーを用意する（利用者が判断した後）

アカウントの作成と前払いは、新しい契約と支払いにあたります。行うと決めた後に進めてください。画面の名前は、各社の変更で変わることがあります。

**OpenAI（GPT-Live 1）**

1. https://platform.openai.com/ にログインします（アカウントがなければ作ります）。
2. 支払い（Billing）で、前払いのクレジットを購入します（最低 $5）。**自動の追加購入（Auto recharge）はオフ**にします。
3. 使用額の上限と通知を設定します。前払いの残高も、この上限も、確実に止まる上限ではありません（集計の遅れで超えることがあります）。
4. 「API keys」で「Create new secret key」を押し、名前（例：`ai-concierge-test`）を付けて作ります。
5. 表示されたキー（`sk-` で始まる長い文字列）をコピーします。**キーはこの1回しか表示されません。**

**Google AI Studio（Gemini 3.8 Live）**

1. https://aistudio.google.com/ に Google アカウントでログインします。
2. 「Get API key」→「Create API key」を押します。
3. 表示されたキー（`AIza` で始まる文字列）をコピーします。
4. 無料枠で使う場合、話した内容はGoogleの製品の改善に使われ、人が読むことがあります。**架空の情報だけ**で話してください。

**キーの扱い**

- キーは、チャット・メール・LINE・Word などに貼らないでください。
- キーは毎回の起動で貼り付けます（このプログラムは、キーをファイルに保存しません）。保管にはパスワード管理ソフトを使ってください。
- 毎回の貼り付けを省きたい場合（任意）：スタートメニューで「環境変数」と検索 →「**環境変数を編集**」（自分のアカウント用）→ 上の欄の「新規」→ 変数名 `OPENAI_API_KEY`（Geminiは `GEMINI_API_KEY`）、値にキーを貼り付け →「OK」。次の起動から「設定済み」と表示され、聞かれなくなります。このPCの中に、キーが保存されることになります。

## 手順5　GPT-Live・Gemini で最初の会話をする

1. 黒い画面が開いたままなら、閉じます（前のサーバーを止めます）。
2. `start_windows` をダブルクリックします。
3. 「OpenAI（GPT-Live 1）のAPIキー」と出たら、コピーしたキーを**貼り付けて（Ctrl+V、または右クリック）Enter** を押します。
   - 画面には何も表示されませんが、入っています。
   - 「受け付けました（sk- で始まる ○○ 文字）」と出れば成功です。
   - 「形が違うようです」と出たら、キーの一部しかコピーできていません。コピーし直して貼り付けます。
4. Gemini のキーも同じように貼り付けます（使わないときは、何も入力せずに Enter）。
5. ブラウザーでログインし、「1. 候補と条件」の **候補** の欄で「OpenAI GPT-Live 1」（または「Google Gemini 3.8 Live」）を選びます。「オフラインの模擬」のままだと、電子音しか鳴りません。
   - 開始の回数の上限はありません。1回の会話は5分で自動的に止まります。
6. 「2. 台本」のカード（C1〜C7）を1つ選びます。カードに、話すセリフが番号の順に書いてあるので、「会話を始める」を押した後、そのとおりに読み上げます。最初はC2がおすすめです。
   - AIが別の順番で聞いてきたら、聞かれたことに合わせて、カードのセリフで答えます。
   - 話し終えたら「以上です」と言い、「終える」を押します（押し忘れても5分で止まります）。
7. 会話を終えたら、判定とメモを記入して「結果を保存」を押します。
8. 管理画面（`http://127.0.0.1:8780/`）の「費用の台帳」で、その会話の留保が「照合待ち」になっていることを確かめます。後日、業者の利用画面で見た実際の額を入力して照合します。

## 会話試験の段取り（C1〜C7）

1. 新しいZIPに入れ替え、`start_windows` で起動して、キーを貼り付けます。
2. 会話試験の画面で、「1. 候補と条件」の **候補** が「OpenAI GPT-Live 1」になっていることを確かめます。
3. 台本のカードを **C1 から順に、1枚につき1回の会話** で行います。
   1. カードを選び、「会話を始める」を押します。
   2. カードのセリフを、番号の順に読み上げます。AIが別の順番で聞いてきたら、聞かれたことに合わせて答えます。
   3. 話し終えたら「以上です」と言い、「終える」を押します（押し忘れても5分で止まります）。
   4. 「5. 判定」の欄の、**そのカードの行だけ**を「はい・いいえ」で記入し、気づいたことをメモに書いて「結果を保存」を押します（1回の会話につき保存は1回）。
4. C1〜C7 が終わったら、開発の担当（Claude）に次を送ってください。
   - カードごとの一言の感想（よかった点・おかしかった点）
   - 管理画面の「費用の台帳」の「試験の会話」の表の写真
   - 保存した結果のファイル（フォルダーの中の `prototype\results\browser-lab` にある `.json`）。チャットに添付します。架空の情報だけなので、添付してかまいません
5. Gemini は、Google AI Studio のキーを用意した後に、同じ段取りで行います。

- 費用の目安：GPT-Live は1回あたり約$0.16（約25円）。C1〜C7で約$1.1です。OpenAIの月の予算（$10）の範囲です。
- C7（ふだんの話し方）は、名乗らずに質問から入るなど、実際のお客様に近い話し方です。採用を決めるうえで、いちばん大事な試験です。

## 終えるとき・次に使うとき

- **終えるとき**：ブラウザーで「終える」→ 判定を記入して「結果を保存」→ 黒い画面を閉じます。
- **次に使うとき**：`start_windows` をダブルクリックします。パスワードは聞かれません。キーは毎回聞かれます（環境変数に保存した場合は聞かれません）。
- **パスワードを忘れたとき**：黒い画面を閉じてから、`reset_password_windows` をダブルクリックし、新しいパスワードを2回入力します。
- **記録の場所**：受付の記録はフォルダーの中の `prototype\data`、会話試験の結果は `prototype\results\browser-lab`、費用の台帳は `prototype\results\usage-ledger.jsonl` です。新しいZIPに入れ替えるときは、これらを新しいフォルダーへ移すと、記録と開始の回数が引き継がれます。

## うまくいかないとき

| 画面に出たこと・起きたこと | 原因と対処 |
| --- | --- |
| PowerShell で `トークン '&&' は、このバージョンでは有効なステートメント区切りではありません` | mac・Linux用の書き方を入力したためです。コマンドは不要です。PowerShell を閉じ、手順3のとおり `start_windows` をダブルクリックします |
| `python3` と入力すると「Python」とだけ出る、または「Python が見つかりませんでした」 | Python が入っていません（Windowsに最初からある案内用の名前です）。手順1を行います |
| 黒い画面に `UnicodeDecodeError: 'cp932' codec can't decode ...` | 古い版のZIPです（2026年10月8日の修正の前）。「ダウンロード」フォルダーの古いZIPと、展開した古いフォルダーを**両方とも消して**から、手順2をやり直して新しいZIPを入れます（消さないと、新しいZIPの名前に「(1)」が付きます）。古い版は起動の前に止まっていたので、消して困る記録やパスワードはありません |
| 黒い画面に「Python 3.11 以上が見つかりません」 | 手順1を行います。入れた後も同じなら、いったんサインアウトするか、PCを再起動します |
| 黒い画面に「ZIP を「すべて展開」したフォルダーの中から開いてください」 | ZIPの中のファイルを直接開いています。手順2の3（すべて展開）を行い、展開したフォルダーの `start_windows` を開きます |
| 黒い画面に「ポート 8780 が使われています」 | 前に開いた黒い画面が残っています。タスクバーで探して閉じてから、もう一度ダブルクリックします |
| ブラウザーに「このサイトにアクセスできません」 | 黒い画面が閉じているか、止まっています。`start_windows` をもう一度ダブルクリックします |
| ログインできない、「5分間お待ちください」と出る | パスワードが違います。5回続けて間違えると5分間ロックされます。忘れたときは `reset_password_windows` |
| マイクのメーターが動かない | ① 住所の欄の左のアイコン → サイトの設定 → マイクを「許可」。② Windowsの「設定」→「プライバシーとセキュリティ」→「マイク」で、マイクへのアクセスとデスクトップアプリを許可。③ ヘッドセットを、Windowsの既定のマイクにする |
| 候補が「（未設定：OPENAI_API_KEY）」となり、選べない | キーを入力していません。黒い画面を閉じ、起動し直してキーを貼り付けます |
| 会話を始めても「プー」という電子音しか聞こえない | 候補が「オフラインの模擬」になっています（AIにはつながっていません）。「1. 候補と条件」の **候補** で「OpenAI GPT-Live 1」などを選んでから始めます。台本のカード（C1〜C7）は話す内容を選ぶもので、接続先は変わりません |
| 候補が「（保留）」となり、選べない | 利用者の判断で保留中の候補です（GPT-Realtime-2.1・ElevenLabs・Cartesia）。正常です |
| 何を話せばよいか分からない | 「2. 台本」のカードに、そのまま読み上げるセリフが番号の順に書いてあります。古い版の画面には書いてありません。新しいZIPに入れ替えてください |
| 「接続情報の発行・接続が2回失敗しました」 | 業者が接続を拒否した（HTTP 400など）か、キー・支払いの設定に問題があります。会話試験の画面と「費用の台帳」の記録に、業者からのエラーの文が残っているので、それをコピーして開発の担当に送ってください。原因を直した後、「費用の台帳」の「失敗の回数を解除」を押します |
| 会話試験の画面に「開始できませんでした：… HTTP 400 …」 | OpenAIがこちらの接続の要求を受け付けませんでした（料金はかかっていません。回数にも数えません）。表示された文をすべてコピーして、開発の担当に送ってください |
| 黒い画面に英語のエラー（Traceback …）が出て止まった | 下の「エラーの文字のコピーの仕方」のとおりコピーし、開発の担当（Claude）に送ってください。このプログラムは、キーとパスワードを画面に表示しないので、そのまま送ってかまいません |

## エラーの文字のコピーの仕方

1. 黒い画面で、`Traceback` から最後の行までを、マウスでなぞって選びます（文字が白く反転します）。
2. **Enter キー**を押します（または右クリック）。これでコピーされます。
   - Windows ターミナルの画面の場合は、選んだ後に Ctrl+C でもコピーできます。
3. チャットに貼り付けて（Ctrl+V）送ります。
4. 黒い画面は、何かキーを押すと閉じます。**閉じる前にコピー**してください。

## 確認できていること・できていないこと

- 開発のサーバーで、日本語のWindowsと同じ条件（ファイルの既定の文字コードが Shift_JIS、時刻帯のデータがない）を作り、起動（パスワードとキーの入力からログインまで）と、すべての自動試験が通ることを確かめています。
- Windowsそのものでのダブルクリックからの起動は、開発のサーバーでは試せません。最初にお使いの画面で確かめていただく必要があります。
