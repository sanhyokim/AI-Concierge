# 客役の自動試験（2026-11-05〜）

利用者の依頼（2026-11-05）：「これらの検証をあなたが客のスタンスで多様なパターンを検証してくれることはできないのですか？」

AIがお客様の役になり、受付のAI（ElevenAgents）と**文字で**自動で会話します。20通りのお客様（ふつうの依頼、先に名乗る人、数が分からない人、番号を言い直す人、煙が出ている人、AIを断る人、営業の電話など）を順に試し、会話のたびに、サーバーが合否を確かめます。

## 1. 何が分かり、何が分からないか

| 分かること | 分からないこと |
| --- | --- |
| 伺う順、番号と日時の復唱と「はい」での確認、清掃の対象と数の質問、FAQの答え、緊急の扱い、AIを止める求め、最後のあいさつと電話を切る処理、使わない言葉・英語・日付の読み方 | 声のこと：聞き間違い、発音、間の長さ、割り込み。これは「声で話す」の試験でしか分かりません |

- 受付のAIは、「声で話す」の ElevenAgents と**同じ指示・同じ業務処理・同じ考えるAI**です。違うのは、声の代わりに文字でやり取りすることだけです。
- 受付の記録は、ほかの試験の通話と同じように残ります（受付履歴に出ます）。
- GPT-Live 1 は対象にしません。GPT-Live の弱点（声のAIがサーバーの文を言い換える）は、声でしか起きないためです。

## 2. 使い方

1. ElevenLabs と OpenAI の両方のAPIキーを入れて起動します（Windows はPCに保存済みのキーをそのまま使います）。
2. 左のメニューの「試験」→ 上の「**客役で試す**」を開きます。
3. 「考えるAI」を選びます（ふつうは GPT-5.6 Terra のまま）。
4. 試すパターンを選びます。最初はすべて選んだままにします。
5. 「始める（有料）」→ 件数と費用の見込みを確かめて「はい、始める」を押します。
6. 1件に1〜3分かかります。進み具合が画面に出ます。ほかの画面に移っても止まりません。途中でやめるときは「止める」を押します（今の会話が終わってから止まります）。
7. 終わったら、表で「要確認」の行を見ます。「会話と確かめたこと」を開くと、会話の全文と確かめた項目が出ます。「開く」で受付記録も見られます。
8. 「結果をテキストで保存」を押すと、`autotest-（日時）.txt` がダウンロードされます。開発の担当にはこのファイルを送ってください。

## 3. 費用

| 費目 | 見込み |
| --- | --- |
| ElevenLabs（文字の会話） | 1通ごとの料金（1通 約$0.003）と、考えるAIの料金。Starter のクレジットから引かれる |
| 客役のAI（OpenAI gpt-6.1-terra） | 1会話 約$0.03〜0.05。OpenAI の月の予算（$10）から |
| 合計 | **1会話 約15〜35円、20件で約300〜700円** |

- 実際の額は、受付記録の「AIの料金」（ElevenLabs が記録した額）と、ElevenLabs・OpenAI の利用画面で確かめます。
- 「費用」の画面では、ElevenAgents の留保は声の会話と同じ分単位の見込みで出ます（文字の会話の実際の額より高めになりやすい）。客役のAIは、OpenAI が返した使用量で計算して、会話の終わりに閉じます。

## 4. 仕組み

- 客のパターン：`prototype/tenants/noda.callers.json`（会社ごとのファイル。ほかの会社は `<会社のID>.callers.json`）。1つのパターンは、人物（persona）・知っていること（facts）・話し方（behavior）・確かめること（expect）です。書き方はファイルの先頭の `_expectの書き方` にあります。
- 受付のAI：ElevenAgents の、文字だけのエージェント「株式会社野田 受付AI（客役の自動試験・文字だけ）」。声の試験のエージェントとは別に作り、そのIDを `prototype/data/elevenagents.json` の `text_agent_id` に残します（声の試験のエージェントは変えない）。会話は、署名付きURLの WebSocket で文字を送り合います（`user_message`・`agent_response`・`client_tool_call`／`client_tool_result`）。
- 客役のAI：OpenAI の Responses API（`POST /v1/responses`、`store: false`）。AIの言葉を受け取り、お客様として次のひと言を書きます。電話を切るときは「（切る）」と書きます。
- 進め方：AIの言葉の後、2.5秒なにも来なければお客様の番です。業務処理の後は、AIの次の言葉を待ちます。AIから40秒なにも来ない、お客様が24回話した、5分を超えた、のどれかで止めます。
- 確かめること（`prototype/autotest/checks.py`）：パターンの expect と、どの会話でも守ること（使わない言葉、4文字以上の英語、`2026-11-10` の形の日付、同じ質問を3回以上）。
- 費用の台帳：ElevenAgents は声の会話と同じ留保（照合待ち）、客役のAIは `openai_lab` に1会話1件で記録します。

## 5. 試験（開発）

- `prototype/tests/test_autotest.py`：模擬の ElevenAgents と模擬の客役で、本物の受付の処理を通した会話・合否・台帳・WebSocket の読み書きを確かめます（外へは何も送りません）。
- `prototype/tests/admin_smoke.cjs`：「客役で試す」の画面（20件の一覧、キーがないと始められない、結果の表）。画面の画像は `screenshots/pc-autotest.jpg`。
- 実際の ElevenLabs・OpenAI との会話は、有料のため、利用者のPCでだけ行います。
