# 会社別の設定（テナント設定）

会社ごとに変わる言葉と項目を、1つのファイルにまとめたものです。AIへの指示や決まった文は、このファイルから作ります。
2社目は、プログラムを書き換えずに、ファイルを1つ足すだけで動かせるようにするためです（設計メモ 2026-11-05、[design-memo-2026-11-05.md](./design-memo-2026-11-05.md) の3章）。

- 野田のファイルは [prototype/tenants/noda.json](../prototype/tenants/noda.json) です。
- 野田の会話の言葉は、このファイルに移す前と1字も変わりません（移す前と後で、AIに渡す文をすべて比べて確かめました）。変わったのは、AIへの話し方の例の「店名・お名前」を「店舗名・お名前」にそろえたところだけです。
- 設定するのは提供する側（私たち）です。お客様の会社が触る画面はありません。FAQ・声・保存期間は、これまでどおり管理画面で変えます。このファイルのFAQは、新しい会社の最初のFAQ（初期値）にだけ使います。

## どの会社の設定を使うか

- 何も指定しなければ、野田（`noda.json`）を使います。
- ほかの会社で動かすときは、起動の前に `AI_TENANT` に、ファイルの名前（`prototype/tenants` の中の `xxx.json` なら `xxx`）か、ファイルの場所を入れます。
- 今は、1つの起動で1つの会社だけを受けます。サーバーで複数の会社を受けるときは、かかってきた番号から会社を決め、すべての記録に会社の印（tenant_id）を付けます（正本 1-12。まだ作っていません）。

## ファイルに書くこと

| 項目 | 内容 | 野田の例 |
| --- | --- | --- |
| `tenant` | 会社名・業種・AIの名乗り・冒頭の案内・締めの言葉・最後のあいさつ | 「株式会社野田、AIオペレーターでございます。」 |
| `intake_fields` | 伺う5つの項目の名前と質問の文。**並べた順が伺う順**です。`asked_with` で、2つを一度に伺えます | ご用件 → ご希望の日時 → 店舗名とお名前 → 折り返しのお電話番号（2026-10-23 の決定） |
| `request_words` | お客様の言葉がご用件だと分かる言葉 | 清掃・点検・ダクト・ロースターなど |
| `follow_ups` | ご用件によって足して伺う質問と、伺う条件、答えの受け方 | 「フードの清掃」なら厨房か上引きか、焼肉店なら何基か（2026-10-26 の決定） |
| `examples` | AIへの指示の中の例（店名・お名前・ご用件・日時） | 焼肉ほのか博多店の田中様、無煙ロースターの清掃 |
| `speech` | 読み間違えやすい言葉のかな、聞き取りで優先する言葉 | 上引き＝うわびき |
| `faq_seeds` | 新しい会社の最初のFAQ | 9件（未承認の推奨案） |
| `demo` | 架空の着信テストと会話試験の模擬の台本、模擬のFAQ | |

次の項目は、**置き場所だけ用意してあり、今は使っていません**。利用者の決定（2026-11-05）で、他社へ販売するときに設計します。野田は、今の決定（緊急の扱いは正本 1-7、料金はFAQのとおり）のままです。

| 項目 | 内容（設計メモ） |
| --- | --- |
| `tenant.business_hours` | 営業時間（時間内・時間外で応答を変えるとき） |
| `triage_rules` | 緊急度 S・A・B・C の判定表（5章） |
| `on_call_roster` | 当番への転送の順番と電話番号（名前・番号は未定） |
| `notification` | 通知の方法と通知先（実際の送信は承認まで行わない） |
| `prohibitions` | この会社だけの、言ってはいけないこと（4章） |
| `fallback` | 当番が出ないときの扱い（転送の待ち時間 20秒など） |

## 新しい会社のファイルを作るとき

1. `noda.json` を写して、`prototype/tenants/<会社の名前>.json` にします（名前は半角の英小文字・数字・`-`・`_`）。
2. 会社名・業種・冒頭と最後のあいさつ・伺う項目の名前と質問・例・FAQ を、その会社の言葉に変えます。
3. `AI_TENANT=<会社の名前>` で起動します。ファイルに足りないものがあれば、起動のときに「会社別の設定に「…」がありません」のように、直すところを表示して止まります。
4. 試験：`prototype/tests/test_tenants.py` は、架空の別の会社（[fixtures/tenant_midori.json](../prototype/tests/fixtures/tenant_midori.json)）で動かし、AIに渡す文に野田の言葉（社名・焼肉・ダクトなど）が1つも混ざらないこと、その会社の順と質問で伺うことを確かめます。プログラムの文字に会社の言葉が残っていないことも確かめます。
