# 費用比較表 v1（案A・案B）

- 確認日：2026年10月4日。単価の出典は `prototype/cost/prices.json`。この文書は `python3 -m prototype.cost.cost_model` で作り直せる。
- **件数・通話時間・通知人数・トークン数はすべて仮定で、利用者の実績ではない。**
- 回線は、完成条件を満たす回線案1（NTTで常時転送し、クラウドで分岐。人への経路はH1）を前提にする。回線案2（代替運用）では、人が受ける通話の追加費用（3章の表）がかからない。
- 為替：1ドル＝150円（仮置き、未確認）。ドル建ての額は税抜に10%を加えてから円に換算する（Twilioは請求されることを確認済み。OpenAI・Anthropic・AWSは税の扱いが未確認なので、安全側として加えている）。NTTは税込の表示、LINEは税別の表示に10%を加えている。
- **未確認の単価は0円にせず、記号で残す**：F（NTT転送の円/分）、V_stt・V_tts（Relayの音声認識・音声合成が別料金になる場合）、V_asr（案Aの入力文字起こし）、S_srv（サーバー）、U_ntt（番号ごとの料金）、R（録音の保存月数。未決定）。

**案Aのトークン数**（1通話・3分あたり。要実測）
- 発信者が話す時間は通話の40%：音声入力 720 トークン（100msあたり1トークン【公式】）
- AIが話す時間は通話の45%：音声出力 1,620 トークン（50msあたり1トークン【公式】）
- 応答の回数 14回（ターン10回と関数呼び出し4回）
  - 応答のたびに、指示文 1,500トークンと会話の履歴を読み直す。これはキャッシュ扱いとし、テキスト 21,000・音声 16,380 トークンになる。
  - 最初の指示文だけはキャッシュされない：テキスト入力 1,500トークン
- 関数の引数などのテキスト出力：300トークン

**案Bの会話モデルのトークン数**（1通話あたり。要実測）
- 入力 1,500、キャッシュ読み取り 24,000、キャッシュ書き込み 3,200、出力 760
- AIが話す文字数：400文字（V_ttsの計算に使う）

**要約**（両案とも、1通話あたり）：入力 3,000トークン、出力 500トークン

## 7. この表から言えること・言えないこと

- 1通話あたりで最も大きいのは、案Aでは音声出力のトークン、案BではRelayの$0.07/分。どちらも仮定のトークン数と時間による。
- 案Bは、V_stt・V_tts（Relayの音声認識・音声合成が別料金かどうか）が確認できるまで、比較が確定しない。
- 回線案1では、人が受ける通話にも転送と発信の費用がかかる。件数が多いほど、この差が大きくなる。
- 採用は、費用だけでは決めない。必須条件と実測の結果を先に見る（設計レビュー3-4）。
